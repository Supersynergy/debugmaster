# Debugmaster v0.1.0 - fail-safe repo diagnostics for humans and AI agents

## Why This Release Matters

Debugmaster gives engineers and coding agents a bounded first pass over unknown repositories. It produces human, JSON, and AI handoff reports without requiring every optional scanner to be installed, and it keeps heavy checks opt-in so large repos do not become unusable by default.

## Highlights

- Added all-in-one repo reports: `debugmaster-report.md`, `debugmaster-report.json`, and `debugmaster-ai-brief.md`.
- Added batch scanning for folders of Git repositories.
- Added safe autofix dry-run/apply mode for low-risk text cleanup.
- Added GitHub pull-request report workflow template.
- Added 64 language/framework stack detection entries with official references.
- Added optional Grepgod and ghmax integration for deeper maps, risk, and pattern mining.
- Changed defaults to fail-safe mode: security scans, full maps, and deep test suites are opt-in.
- Fixed minimal Linux behavior when optional tools are missing.

## Quick Install

```bash
git clone https://github.com/Supersynergy/debugmaster.git
cd debugmaster
./install.sh --link
debugmaster init
debugmaster all . --timeout 60
```

## Deep Verification

```bash
debugmaster all . --check-profile deep --security --full-map --timeout 120
```
